---

| 现象 | 处理 |
| --- | --- |
| 下载超时 | 换镜像或携带归档与 SHA256SUMS 离线安装 |
| 无对应资产 | 核实平台或使用源码构建 |
| 哈希缺失/不符 | 停止安装，从可信正式发布重新下载 |
| 后台无法打开 | 检查实际端口、私密配置和本地服务状态 |
| 登录失败 | 从安装目录读取本地管理员配置 |
| 订阅为空 | 检查节点源、提供者、令牌有效期、配额和格式能力 |
| 某格式缺少节点 | 查询 `/api/v1/formats`，无法表达的协议会筛除 |
| 加密节点不执行 | 设置兼容内核及本地 SOCKS5 上游 |
| Windows 链接失败 | 安装 MSVC C++ Build Tools、Windows SDK，使用对应开发终端 |
| 快速验证通过但发布失败 | 快速模式不包含完整编译、服务 E2E 和多平台包检查 |

公共 issue 只报告版本、平台、错误类别及合成重现输入，不贴真实日志、完整订阅 URL、节点安装器或服务器地址。
