title: 隐私与公开仓库
---

仓库与公开资产只保存源码、合成测试数据和公开模板。改为 public 会公开可达 Git 历史；普通删除提交不能删除旧版本，公开前必须检查完整历史。

| 数据 | 处理 |
| --- | --- |
| 密码、订阅凭据、提供者 token | 本地私密配置或环境变量，不提交 |
| 用户、配额、目的地址统计 | 本地私密数据，限制权限和保留期限 |
| 生成安装器和链接 | 可能含凭据，默认忽略，不上传 |
| 管理登录令牌 | sessionStorage，会话结束清除 |
| 语言和镜像偏好 | 本地非敏感浏览器偏好 |
| 公开模板 | `change-me`、空值、保留测试地址 |

前端加载同源资源，不使用远程字体、统计 SDK 或 CDN。服务不做第三方公网 IP 查询；上游订阅、提供者心跳和统计中继仅在用户明确配置后访问。安装过程会访问公开 GitHub 及选择的镜像。生成订阅无默认第三方测速地址。

目的地址统计 `record_domains` 默认关闭，仅在明确启用时记录；未启用时仍提供聚合流量和连接数。关闭后重新启动 Client 不再向统计接口返回以前保存的目的地址，后续保存时清理该历史。本地日志仍可能含运行信息，应妥善保护。无遥测不等于本机从不处理私密数据。

```bash
python scripts/check-privacy.py --history
gitleaks git --config .gitleaks.toml --redact
```

分别检查公开候选工作树、暂存区、历史文件、提交与标签元数据及制品。报告只列路径或对象标识和规则，不回显秘密。发现真实历史凭据时先撤销或轮换，再清理可达引用；外部已经复制的数据无法靠重写历史收回。
